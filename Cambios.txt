# Cambios a realizar en la pagina 📝

Acá meteremos todos los cambios que se deben hacer en los archivos al subir una nueva modificacion con boostrap, 
a continuacion se muestra como se debe proceder para implementar un cambio en boostrap:



1) Descargar la version mas reciente del proyecto con git pull
si te da problemas por merge (tenias cambios en tu equipo) hace: git stash y despues git pull, ahi le decis a git que se cague en tus cambios y solo descargue lo que este en la pagina



2) Trabajar con boostrap y hacer los cambios que se quieran realizar
2.1) Si no tenes licencia entrar a https://bootstrapstudio.io/student-pack
2.2) Ingresar con perfil de git hub pro
2.3) Te da un numero de licencia, copiar pegar y listo.



3) Guardar el boostrap



4) Borrar todos los archivos de la carpeta salvo boostrap, readme, cname, los posibles pdf que se encuentren, el 404.html, robotito.jpg y cambios.txt (este archivo)



5) Consola: git add -A
	    git commit -m "mensaje que se quiera poner según los cambios realizados"
	    git push
(si hubo merge llamar a mati porque hay que modificar los archivos para indicarle a github que cambios queremos guardar y cuales no, usualmente se borran los archivos que salen del merge igualmente).



6) Desde boostrap exportar los cambios a los archivos del proyecto en esta carpeta
6.1) Setear la carpeta
6.2) Export y save


7) Realizar los cambios que se listan en "LISTA DE CAMBIOS" (al final de este archivo) para cada archivo.



7) Guardar todos los archivos modificados.



8) Consola: git add -A
	    git commit -m "mensaje que se quiera poner según los cambios realizados"
	    git pull
	    (si hubo merge contactarse con mati, sino continuar)
	    git push.
