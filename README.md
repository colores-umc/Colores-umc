# Colores 🎨
La idea de este repositorio es albergar todos los contenidos necesarios para la pagina web de Colores.

## Comenzando 🚀 

_Estas instrucciones te permitirán obtener una copia del proyecto en funcionamiento en tu máquina local para propósitos de desarrollo y pruebas._

Para descargar el proyecto por primera vez hay que clonar 👯 el repositorio en una carpeta de tu agrado, esta accion se puede hacer desde la app github desktop instalada previamente en el equipo.


### Pre-requisitos 📋

_Que cosas necesitas para instalar el software y como instalarlas_

Para correr el programa necesitas la version de Bootstrap Studio 4, para asi poder abrir los archivos de esta version.
Mucho cuidado, con otra version no se podra abrir el archivo
```
Incluso si la version desde la que se desea abrir el archivo es mas nueva que la del archivo original.
```

## Ejecutando las pruebas ⚙️

Para ejecutar pruebas desde bootstrap studio recorda que arriba a la derecha hay una ventanita que dice preview, al costado una flecha que indica que al abrirla podras habilitar las previews una vez habilitada esta opcion al apretar en preview podras ver el proyecto desde tu navegador de preferencia


## Para Realizar modificaciones 💻

Para realizar modificaciones de este proyecto primero debe asegurarse que nadie del equipo este trabajando en este proyecto en ese momento para evitar problemas indeseados de merges. Esto es asi debido a que al utilizar bootstrap studio es complejo trabajar solo en algunos archivos y en otros no, lo que dificulta la separacion de tareas sin pisar trabajos.
Una vez hecho esto hacer un fetch y un pull del proyecto, abrir el proyecto desde bootstrap studio (version 4) y modificar todo lo que se quiera, una vez listo guardar en la carpeta donde se hizo el clonado de este repo, antes de salir de la aplicacion, borrar todos los archivos de la carpeta clonada salvo el archivo de boostrap studio recien guardado, entonces debemos exportar desde el boostrap studio los archivos en la carpeta que clonamos. Esto nos permite por un lado guardar la version de bootstrap studio y exportar todos los archivos generados por este programa con los que funcionara la pagina.
Para finalizar entrar a github escribir un commit que detalle lo que se agrego, modifico o elimino y una descripcion no viene mal tampoco 😏 y pushear.
Avisar siempre a los demas miembros del equipo que se termino de trabajar.

_Por ejemplo mati se va a poner a cambiar una imagen, entonces pregunta, alguien esta trabajando con el proyecto? si alguien lo esta haciedo debera esperar a que termine, si no, debera abrir github desktop poner fetch, pull y abrir el archivo bootstrap, cambia la imagen, guarda el boostrap, borra todos los archivos de la carpeta en la que estaba trabajando (la clonada) salvo el .bsdesign y exporta desde el boostrap studio el trabajo realizado en la carpeta clonada. una vez hecho esto entra a github desktop y pone un commit relacionado a lo que hizo ej "cambie fotito ppal por una mas linda" y una descripcion "la anterior no le gustaba a sandra" y para finalizar apreta push._
